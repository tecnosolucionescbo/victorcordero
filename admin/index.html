Generador de contenido para el portafolio

📋 Instrucciones para tu cliente

  1. Llena el formulario con los datos de la fotografía
  2. Copia el código JSON generado
  3. Ve a data/portfolio.json en tu repositorio de GitHub
  4. Pega el nuevo objeto dentro del array (después del último } y antes del ])
  5. Sube la imagen a images/portfolio/ con el mismo nombre que pusiste en "Ruta de imagen"
  6. ¡Listo! El sitio se actualizará automáticamente
